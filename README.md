# Medici English

Персональный тренажёр английского языка: двухминутные уроки, карточки, озвучивание, регистрация и индивидуальный прогресс.

## Сборка и проверка

Требуется Node.js 24 или новее.

```sh
node build.mjs
node test.mjs
```

Сборка создаёт Cloudflare Worker в `dist/server/index.js`. Для развёртывания нужен серверный хостинг Cloudflare Workers с базой D1, привязанной как `DB`. Начальная схема — `drizzle/0000_accounts.sql`. GitHub Pages не поддерживает серверную часть приложения.

Репозиторий содержит только исходный код и тесты, без базы данных учеников, реальных паролей, токенов и идентификатора проекта текущего хостинга. Для развёртывания создайте собственный проект и настройте его привязки.

## Структура

- `public/` — интерфейс и учебные материалы.
- `worker/` — серверная часть.
- `drizzle/` — схема базы данных.
- `build.mjs` — сборка.
- `test.mjs` — локальные тесты регистрации и прогресса.
